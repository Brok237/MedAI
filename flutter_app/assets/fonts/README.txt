FONTS — Download Required
=========================

The app uses the Poppins font family from Google Fonts.
These files are NOT included because of licensing redistribution rules.

Download link (free, OFL license):
  https://fonts.google.com/download?family=Poppins

After downloading, extract and place these 4 files here:
  assets/fonts/Poppins-Regular.ttf
  assets/fonts/Poppins-Medium.ttf
  assets/fonts/Poppins-SemiBold.ttf
  assets/fonts/Poppins-Bold.ttf

The pubspec.yaml is already configured to use them.
If you prefer NOT to use Poppins, remove the fonts section
from pubspec.yaml and the app will use the system default font.
